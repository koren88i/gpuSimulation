# Project continuation instructions

1. Read `docs/HANDOFF.md` before continuing research or changing this project. Read `docs/INFERENCEX_METHOD.md` before editing extraction/calculation logic.
2. The user wants data files, a readable report and the interactive explorer at `/report/`. Read `docs/REPORT_UI.md` for UI work. All numerical derivation and report tables must be generated by code. Do not hand-edit numerical results in generated CSV/JSON/Markdown reports.
3. Compare the same actual model and hardware at equal total GPU budgets. Keep model-version aliases separate. Use the same profile on both sides. Split capacity is modeled by multiplying smaller measured deployments; larger capacity is measured at an observed point.
4. Do not assume unified always wins. Preserve negative gains and distinguish observed points from proven capacity maxima. Do not add per-request latencies when multiplying independent copies.
5. Keep GB200/GB300 four-GPU tray units separate from eight-GPU server units. API GPU fields have known conflicts; never silently treat TP times EP as physical GPU count.
6. Root-session concurrency in AgentX is different from fixed-sequence request concurrency. DAU assumptions are configurable planning inputs, not measured human behavior. The default fixed-sequence coding proxy is disabled.
7. Preserve raw snapshots and source-artifact provenance. Document unresolved validity, dataset-revision, host-placement and sweep limitations. Missing data stays null.
8. Generated outputs are in `reports/inferencex/`. `shortlist.js` preserves five editorial examples; `verify-qualified.js` audits every qualified pair using `manifest-qualified.json`. Audit status is separate from shortlist membership and maximum-capacity evidence. Refresh browser data with `export-ui.js` after relevant report/audit changes. Run the relevant suites in `tests/inferencex.test.js`, `tests/qualified-audit.test.js` and `tests/report.test.js`.
9. Keep the existing simulator untouched unless the user requests integration. The reference checkouts `research-inferencex/` and `research-inferencex-app/` are inspection sources, not our application code. Their own AGENTS.md files apply within those directories.
10. Update `docs/HANDOFF.md` and `docs/WORK_LOG.md` after material work so another session can continue. Do not delete older user artifacts, commit, push, or deploy as a side effect of documentation/research work.
11. Preserve explicit per-copy × multiplier = combined-total displays; never multiply a split total again. Do not interpret configured concurrency as measured maximum capacity. The five audited examples are the default collection; all 318 records must remain accessible with All operating points, and collection changes reset filters. Public Site version 13 is current; versions 10 through 12 and the earlier research ZIP are stale. Consult the handoff before publishing or packaging.
